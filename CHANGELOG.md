# История изменений

## 0.1.0 — 2026-10-31

- Первый рабочий прототип SwitcherMax под Windows 10/11 x64.
- Преобразование выделенного текста EN ↔ RU с настраиваемыми глобальными горячими клавишами.
- Три режима: автоматически, EN → RU, RU → EN.
- Эвристика сохранения пунктуации, системный трей, автозапуск и настройки.
- Самодостаточная сборка .NET 8, NSIS-установщик.
- Фирменная иконка EXE, трея и установщика, собственные всплывающие уведомления.
- 15/15 проверок алгоритма — PASS; ручная проверка работы в поле ChatGPT — PASS.

Ограничения: интеграционные проверки в разных приложениях, надёжность буфера обмена и полный цикл обновления/удаления пока не покрыты автоматическими тестами.
