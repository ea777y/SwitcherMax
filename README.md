# SwitcherMax

**SwitcherMax** — небольшая офлайн-утилита для Windows, исправляющая текст, набранный в неправильной русской/английской раскладке. Программа ничего не исправляет автоматически: выделите текст и нажмите выбранную горячую клавишу.

> **Статус:** v0.1.0 — рабочая тестовая версия. Сборка и тесты алгоритма успешно пройдены на Windows 11, работа горячей клавиши подтверждена в текстовом поле браузера. Полная совместимость со всеми приложениями и буферами обмена не гарантируется.

## Возможности

- Преобразование **EN → RU**, **RU → EN** и автоматический выбор направления по преобладающей письменности.
- Глобальные настраиваемые сочетания клавиш без требования Pause, Break или Scroll Lock.
- Работа с выделенным текстом, включая многострочный, с сохранением регистра и пробелов.
- Дополнительный режим обработки пунктуации (это **не** проверка орфографии).
- Системный трей, пауза, окно настроек, опциональный автозапуск с Windows.
- Фирменная иконка приложения и всплывающие уведомления.
- Не требует интернета; текст не отправляется на сервер.

## Использование

1. Выделите ошибочно набранный текст в приложении.
2. Нажмите горячую клавишу:

| Сочетание по умолчанию | Действие |
| --- | --- |
| `Ctrl + Alt + Q` | Автоматическое определение направления |
| `Ctrl + Alt + E` | EN → RU |
| `Ctrl + Alt + R` | RU → EN |

3. Изменить сочетания, обработку пунктуации и автозапуск можно в окне настроек (двойной щелчок по значку в трее).

`Ctrl + Alt` иногда пересекается с `AltGr` и назначениями других программ. При необходимости измените сочетания.

## Установка

Скачайте `SwitcherMax_Setup_v0.1.0_x64.exe` со страницы [Releases](https://github.com/ea777y/SwitcherMax/releases), запустите установщик и следуйте шагам мастера. Установщик содержит автономную сборку .NET: **отдельная установка .NET SDK на пользовательском ПК не нужна**.

Поддерживаемая архитектура пакета: **Windows x64**. Перед обновлением или удалением завершите SwitcherMax через меню трея.

## Сборка из исходников

Требуется **.NET 8 SDK** и PowerShell 7 (на Windows):

```powershell
dotnet --version
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build-windows.ps1
```

Готовая автономная сборка появится в `dist\win-x64\SwitcherMax.exe`.

Для сборки установщика дополнительно установите **NSIS 3**:

```powershell
winget install -e --id NSIS.NSIS --source winget
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build-setup.ps1
```

Установщик появится в `dist\setup\`. **Не запускайте собранный EXE из `dist\win-x64` во время его пересборки**: Windows не позволит заменить работающий файл.

## Структура проекта

- `src/SwitcherMax/` — WinForms-приложение, обработка выделения и конвертация.
- `tests/SwitcherMax.Tests/` — тесты алгоритма конвертации.
- `assets/icons/` — фирменные иконки приложения и трея.
- `installer/SwitcherMax.nsi` — сценарий автономного установщика NSIS.
- `build-windows.ps1`, `build-setup.ps1` — сборка EXE и установщика.

## Известные ограничения

В v0.1.0 выделение читается через `Ctrl+C`, а преобразованный текст вставляется через `Ctrl+V`. Программа пытается сохранить и восстановить исходный буфер обмена, но некоторые нестандартные форматы, асинхронные редакторы, защищённые поля и приложения с повышенными правами могут работать иначе. Не тестируйте на единственном экземпляре важного документа и не используйте в полях паролей. При ошибке в редакторе обычно доступна отмена через `Ctrl+Z`.

Пока подтверждены 15/15 проверок алгоритма, успешная сборка EXE и NSIS-установщика, запуск установленной программы и работа в интерфейсе ChatGPT. Дополнительные интеграционные проверки остаются открытыми.
